Made with Gemini and some help by Opus, GLM and Deepseek.

Copy the folder from the archive to /PSP/GAME. The program looks for the TES II files (the `arena2` and `music` directories) relative to the folder from which it is launched.

Controls (with the HUD hidden)

Analog stick — move forward/backward and strafe left/right
D-Pad Left/Right — turn camera (also Square / Circle)
D-Pad Up/Down — tilt camera up/down (also X for down, Triangle for up when held)
R-Trigger — attack
L-Trigger — run (hold to activate)
L + R — jump
Start — interact: open doors, pull levers, search corpses
Triangle — open inventory (press again while in the inventory to view the character sheet)
Select — show/hide the HUD
L + Select — noclip mode

With the HUD visible

Use the D-Pad to select icons

X — select

Portrait — character sheet
Options — settings menu
Book — spellbook
Eye — environment interaction mode (cycle options using Square)
Sacks — inventory
Swords — attack
Orb — repeat active spell
Feet — movement mode (Walk/Run/Sneak)
Scroll — 3D dungeon map
Campfire — rest

Inventory

Navigate using the D-Pad

X — select
Triangle — move weapon to the other hand
Square — quick-drop an item
Circle or Start — close the inventory

Currently, the game consists only of the "Privateer's Hold" dungeon. Basic mechanics have been implemented, including dungeon exploration, combat, looting, skill and level progression, and death.

There are some differences compared to the original game. Specifically, once the music in a dungeon ends, it will be replaced by a track chosen at random from a pool of dungeon-themed pieces. An agent implemented this, and I decided to keep it.

Tested on PPSSPP and an actual PSP-3004. Naturally, while PPSSPP delivers a smooth, fast image, the PSP runs at around 20–25 FPS—much like a subpar computer from the era when TES II was first released.
